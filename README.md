# Ground-Station-Satellite-Antenna-Position-Control-Using-a-DC-Servo-Motor
MATLAB/Simulink study project based on the IEEE Access paper “Enhanced Antenna Positioning Control System Using Adapted DC Servo Motor and Fuzzy-PI Controller.” Models and controls a ground-station satellite antenna driven by a DC servo motor, comparing PID, LQR, and Mamdani Fuzzy-PI controllers for position tracking.
